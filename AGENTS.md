# Repository instructions

Codex Cloud feladatban ne hozz létre és ne módosíts új bináris képfájlt. Az új vagy szerkesztett PNG-, JPG-, WebP-, ICO- és más bináris asseteket először közvetlenül GitHubra kell feltölteni. A Codex csak a repositoryban már meglévő assetekre hivatkozzon, vagy kódalapú megjelenítést használjon.

Aloldalak: minden önálló program saját route-ot, saját layoutot és izolált stílust kap (itt maga a teljes app a `/calm-touch` basePath alatt), a háttéranyagai a `docs/<program>` mappába kerülnek.
